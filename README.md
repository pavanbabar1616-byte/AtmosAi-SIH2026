# 🌤️ AtmosAi

## AI-Powered Automatic Weather Station Quality Control & Sensor Health Platform

### Problem Statement: SIH26073

### Tagline: Detect. Explain. Protect.

---

## 📋 Overview

AtmosAi is an AI/ML-powered operational platform for monitoring the quality and reliability of Automatic Weather Station (AWS) observations. The system combines traditional weather-data quality control with machine-learning anomaly detection to identify unreliable AWS observations and help operators take corrective action.

---

## 🚀 Features

- **Real-time Anomaly Detection** - Detects spikes, frozen values, drifts, and communication errors
- **Explainable AI (XAI)** - Explains WHY an observation was flagged as anomalous
- **Sensor Health Monitoring** - Tracks sensor reliability and calibration drift
- **Interactive Dashboard** - Visualization of stations, anomalies, and health metrics
- **Spatial Analysis** - Compares suspicious observations with nearby stations
- **Multivariate Analysis** - Analyzes temperature, pressure, and humidity together
